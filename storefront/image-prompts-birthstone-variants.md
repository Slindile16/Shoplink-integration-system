# Birthstone image variants

Generated using the built-in image generation tool, editing the original January garnet image. Final WebP assets: `dist/assets/birthstone-story-{month}.webp` (lowercase English month), including January re-encoded from the original. No colour filters are used. Images are illustrative concept photography.

One accepted birthstone is offered for each month, verified against [American Gem Society](https://www.americangemsociety.org/birthstones/) and [GIA](https://www.gia.edu/birthstones). June uses alexandrite, October pink tourmaline and December tanzanite. Other accepted stones for those months are not offered in this collection. All month options use the fictional catalogue price of R14,900.
